# Golla Ravi Kumar — Portfolio

A personal portfolio for my data analysis and business intelligence projects, skills, education, and internship experience.

## Features

- Responsive navigation and page layout
- Project cards with illustrative dashboard previews
- Sections for skills, projects, internship, education, certifications, and contact
- Email links for contacting me and requesting my resume

The dashboard previews are illustrative and are not project screenshots or reported results.

## Built with

- React and TypeScript
- Vite
- CSS
- Lucide icons

## Run locally

Install the dependencies and start the development server:

```bash
npm install
npm run dev
```

Vite prints the local address when the server starts.

## Production build

```bash
npm run build
npm run preview
```

The production files are generated in `dist/`.
